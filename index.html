뒷영어 운영 도구

뒷영어 채널 운영자가 승인한 영어 학습 영상을 업로드하고 게시 일정을 관리하는 개인용 프로그램입니다.

주요 기능

  • Google 계정으로 연결한 채널 확인
  • 완성한 영상의 비공개 업로드와 처리 상태 확인
  • 영상 제목·설명·표지 관리
  • 운영자가 승인한 일정에 따른 공개 전환 준비

YouTube Data API Services를 사용합니다. 현재 비공개 업로드와 표지 적용을 확인했으며, 자동 공개 게시 기능은 준비 중입니다. 외부 사용자의 계정을 모집하거나 연결하는 서비스는 제공하지 않습니다.

계정 연결과 정보 관리

Google의 인증 화면에서 권한을 승인합니다. 이 프로그램은 Google 계정 비밀번호를 수집하지 않습니다. 연결한 계정과 영상에 대한 작업은 채널 운영자가 승인한 범위에서 수행합니다.
