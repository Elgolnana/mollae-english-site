뒷영어 운영 도구는 채널 운영자가 자신의 영상을 관리하는 개인용 프로그램이며 YouTube API Services를 사용합니다.

접근하고 보관하는 정보

Google OAuth 접근 토큰·갱신 토큰·승인 권한·만료 정보, 연결된 채널의 식별 정보, 업로드한 영상의 ID·링크·제목·설명·처리 및 공개 상태를 취급합니다. 운영자가 제공한 영상·표지·게시글과 작업 결과도 보관합니다. Google 계정 비밀번호는 수집하지 않습니다.

이용 목적과 공유

채널 확인, 승인된 영상 업로드, 표지 및 영상 정보 수정, 게시 일정 실행과 오류 확인에 사용합니다. 인증 및 영상 관리 요청에 필요한 정보를 Google/YouTube에 전송합니다. 운영자가 사용하는 비공개 작업 문서와 Notion 일정에 영상 링크·게시 상태를 기록할 수 있습니다. 인증 토큰은 이러한 문서나 Notion에 기록하지 않습니다.

Google 사용자 데이터를 광고 목적으로 이용하거나 판매하지 않습니다. Google API에서 받은 정보의 이용과 다른 앱으로의 전달에는 Google API Services User Data Policy의 Limited Use 요구사항을 적용합니다.

보관과 삭제

인증 정보는 운영 서버의 접근이 제한된 별도 저장소에 보관합니다. 연결 해제 또는 삭제 요청 시 관련 인증 정보와 API로 수집한 정보를 삭제하는 운영 절차를 적용합니다. 삭제 범위에는 인증 백업과 작업 기록, 운영 문서에 복사한 API 정보도 포함됩니다. YouTube에 업로드된 영상 삭제는 별도로 채널 운영자가 결정합니다.

인증 정보는 연결 유지에 필요한 기간 동안 보관합니다. API 조회 정보는 30일 이내에 다시 확인하거나 삭제합니다. 연결 해제 또는 삭제 요청을 확인하면 운영자가 수동으로 처리하며, 관련 토큰·백업·API 정보는 7일 이내에 삭제합니다. 자동 삭제 기능은 제공하지 않습니다.
